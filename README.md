# shy

A lightweight Chrome extension that blurs the side menu content in ChatGPT for privacy. Made for shy people who want to keep their conversations private.

## Features

- **Blur ChatGPT sidebar** - Keeps your conversation history private
- **Configurable blur intensity** - Adjust how blurred the content is
- **Hover to reveal** - Move your mouse over the sidebar to temporarily see content
- **Keyboard shortcut** - Press `Alt+S` to toggle blur on/off (customizable)
- **Toggle button** - Enable/disable via popup menu

## Installation

### From source

1. Clone this repository:
   ```bash
   git clone https://github.com/yourusername/shy-extension.git
   ```

2. Open Chrome and go to `chrome://extensions/`

3. Enable "Developer mode" (top right)

4. Click "Load unpacked" and select the `shy-extension` folder

5. The extension will be installed and active on ChatGPT

## Usage

- **Default**: Blur is enabled by default when you visit ChatGPT
- **Toggle**: Click the extension icon or press `Alt+S`
- **Configure**: Click the extension icon to adjust settings
- **Reveal**: Hover over the blurred sidebar to see content temporarily

## Settings

- **Enable blur** - Turn blur on/off
- **Blur intensity** - Slider from 2px to 20px
- **Keyboard shortcut** - Click to set custom shortcut
- **Hover to reveal** - Enable/disable hover reveal
