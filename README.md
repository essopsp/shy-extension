<h1 align="center">shy</h1>

<p align="center">
  <b>Blur the side menu content in ChatGPT for privacy.</b><br>
  Made for shy people who want to keep their conversations private.
</p>

## Features

- **Blur ChatGPT sidebar** - Keeps your conversation history private
- **Configurable blur intensity** - Adjust how blurred the content is
- **Hover to reveal** - Move your mouse over the sidebar to temporarily see content
- **Keyboard shortcut** - Press `Alt+S` to toggle blur on/off
- **Toggle button** - Enable/disable via popup menu

## Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/essopsp/shy-extension.git
   ```
2. Open Chrome and go to `chrome://extensions/`
3. Enable **Developer mode** (top right)
4. Click **Load unpacked** and select the `shy-extension` folder
5. The extension will be active on ChatGPT

## Usage

| Action | Method |
|--------|--------|
| Toggle blur | Click the extension icon or press `Alt+S` |
| Adjust intensity | Open popup and drag the slider |
| Reveal content | Hover over the blurred sidebar |
| Configure | Click the extension icon |
